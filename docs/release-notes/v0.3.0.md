**Windows stay private until you share them.** A connected AI agent sees nothing on your screen
until you share a window with it. A window you have not shared looks to the agent exactly like one
that is not open: no title, no app name, no pixels, no text, no controls. A video playing on the
side stays private.

The build is unsigned, so Windows SmartScreen warns on first run: click **More info → Run anyway**.
Installing over 0.2.0 keeps your settings and MCP token.

### Sharing

- **The share key.** Click into a window and press `Ctrl+Shift+F8`. A dialog names the window and its
  app before anything is shared (*Don't share* is the default). Press the key again there to stop.
- **The agent asks.** When it needs a window, the overlay (not the agent) asks you to click into it
  and confirm. The agent never names the window, so it cannot find out what is open by asking.
- **The tray menu.** *Shared with the AI* lists everything shared; stop any of it, or everything.
- A shared window brings its own menus and dialogs. For most apps you can share all of the app's
  windows at once; never for browsers or Explorer, whose windows are unrelated things.

### What the agent can and cannot learn

- Screenshots are built from each shared window's own picture on a blank background, so nothing of
  any other window, the desktop, the taskbar or a notification is in them. Nothing is ever copied
  from the screen: a shared window that cannot draw itself (some games and video players) is blank.
- The agent is not told which window you are working in, and what it hears about windows covering a
  control is measured over shared windows only, so a private window moving around changes nothing.
- Stopping a share during a tool call returns nothing that call read, and the overlay deletes its
  screenshots of that window.
- The overlay's own questions carry its badge, and an agent's words that pose as the app are labelled
  as the agent's. The overlay never reads its own questions aloud, and the panel marks the agent's
  activity lines with **AI**.

Stopping a share is not retroactive: what an agent already saw stays in its conversation. Sharing
governs this overlay only; an agent with its own shell or file access can still read your screen
outside it.

### Known limitations

- The new sharing paths have been tested against a fake desktop and the packaged app's server, but
  not yet end to end on Windows. Please report anything that looks wrong.
- The built-in chat panel needs `@anthropic-ai/claude-agent-sdk`, which is not bundled with the
  installer; use the overlay from Claude Code or another MCP client.
