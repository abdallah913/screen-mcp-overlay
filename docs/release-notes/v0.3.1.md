**A fix for 0.3.0 and every earlier release:** the UI Automation helper needed the Visual C++
runtime (`VCRUNTIME140.dll`), which Windows does not include and the installer did not ship. On a PC
that never installed the Visual C++ redistributable, the helper did not start, so the overlay could
not read or point at any window. It now carries its own runtime and needs nothing extra.

Everything else is as in [0.3.0](https://github.com/abdallah913/screen-mcp-overlay/releases/tag/v0.3.0):
**windows stay private until you share them.** A connected AI agent sees nothing on your screen until
you share a window with it (`Ctrl+Shift+F8` in that window, confirming the dialog), and a window you
have not shared looks to the agent exactly like one that is not open.

### Download

| File | Use |
|---|---|
| `ScreenMcpOverlay-Setup-0.3.1.exe` | **Recommended.** Installs for your user by default, with no admin needed (an all-users install is offered, and asks for admin), with Start-menu and desktop shortcuts and an uninstaller |
| `ScreenMcpOverlay-Portable-0.3.1.exe` | One file, nothing installed. Starts a little slower, since it unpacks itself each time |
| `SHA256SUMS.txt` | Checksums of both |

The build is unsigned, so Windows SmartScreen warns on first run: click **More info → Run anyway**.
Installing over an earlier version keeps your settings and MCP token.

### Known limitations

- The sharing paths have been tested against a fake desktop and the packaged app's server, but not
  yet end to end on Windows. Please report anything that looks wrong.
- The built-in chat panel needs `@anthropic-ai/claude-agent-sdk`, which is not bundled with the
  installer; use the overlay from Claude Code or another MCP client.
