**Quit now quits.** Choosing *Quit* in the tray menu left the app running, tray icon and all: the
overlay windows the app draws on cannot be closed by design, and Windows' quit gave up when it
reached them. They are now removed as the app starts to quit, so it ends at once.

Everything else is as in [0.3.1](https://github.com/abdallah913/screen-mcp-overlay/releases/tag/v0.3.1)
and [0.3.0](https://github.com/abdallah913/screen-mcp-overlay/releases/tag/v0.3.0): windows stay
private until you share them (`Ctrl+Shift+F8` in a window, then confirm), and the UI Automation
helper needs nothing extra installed.

### Download

| File | Use |
|---|---|
| `ScreenMcpOverlay-Setup-0.3.2.exe` | **Recommended.** Installs for your user by default, with no admin needed (an all-users install is offered, and asks for admin), with Start-menu and desktop shortcuts and an uninstaller |
| `ScreenMcpOverlay-Portable-0.3.2.exe` | One file, nothing installed. Starts a little slower, since it unpacks itself each time |
| `SHA256SUMS.txt` | Checksums of both |

The build is unsigned, so Windows SmartScreen warns on first run: click **More info → Run anyway**.
If an older version is still running in the tray, end it from Task Manager (*Screen MCP Overlay*)
before installing, since its Quit did not work. Installing over an earlier version keeps your
settings and MCP token.
